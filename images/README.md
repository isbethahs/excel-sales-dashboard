# 📊 Análisis de ventas en Excel - NovaRetail Group

## 🎯 Objetivo
Analizar el rendimiento de ventas para identificar oportunidades de crecimiento y optimización del negocio.

## 🧠 Problema de negocio
La empresa necesita entender qué productos, regiones y segmentos generan mayores ingresos y cuáles requieren mejora.

## 🛠 Herramientas
- Excel (tablas dinámicas, dashboards, análisis de datos)

## 📊 Dashboard

![Dashboard](images/novaretail-sales-dashboard.png)

## 🔍 Proceso
- Limpieza y organización de datos
- Creación de tablas dinámicas
- Construcción de dashboard interactivo
- Análisis de métricas clave

## 📈 Insights clave
- Identificación de productos más rentables
- Regiones con mejor desempeño
- Tendencias de ventas a lo largo del tiempo

## 💰 Impacto
- Mejora en la toma de decisiones comerciales
- Identificación de oportunidades de crecimiento

## 🚀 Conclusión
El análisis permitió transformar datos en información clave para optimizar la estrategia de ventas.
